QRStream

Send a file

Pick a file. This screen turns it into a stream of QR codes. Film it with the receiver on any phone. The file never leaves this page except as light.

How it works
  1. Open the receiver on the phone: scan the code shown when the stream starts, or go to .
  2. Tap Start Camera and hold the phone so the whole code is in the frame.
  3. Missed codes do not matter: every code is new (fountain code), and any set slightly larger than the file rebuilds it.
  4. The phone checks SHA-256, then shows the file with Open, Save, Share and Email.
